# 不依赖编排框架的研究方法验证

采用状态：用户要求撤回本轮修改，当前 skill 已恢复为本实验的 before / p01 版本（用户称 v2），全部 106 个文件与冻结快照一致。以下实验过程、回答和结论作为历史记录保留，不代表新版仍在使用。

日期：2026-09-10。开发诊断，比较本轮修改前后的 skill；不是与无 skill 的增量实验，也不是跨宿主兼容性认证。

本轮确认了新版可以在禁用 subagent 和工作流的条件下完成研究，没有显示明确的质量优势，独立匿名评审小幅偏好旧版。两组均形成“经营前景积极、当前价格吸引力一般”的判断；旧版追到了更新的供电架构路线，新版补了竞争交付和现金流归因。不能把方法更通用直接等同于研究质量已经提高。

## 改动范围

核心方法统一放在 `references/capabilities/research.md`，来源处理在 `references/methods/evidence-and-sources.md`，`pipeline.md` 只说明宿主支持委派时如何分工。没有新增运行框架、数据库、依赖或子能力。

- 整体研究在选择主要深查方向前，对照经营披露与财报之外的重大业务变化；早先宣布但仍在推进的项目追到当前状态。
- 下一步按经济重要性及区分解释的能力选择；新关系可以改变研究方向，不因原先选择了某个证券或财务问题而排除其它方向。
- 关键网页失败时按事项、主体和日期寻找其它原始入口，区分正文、片段、部分可读和失败；复杂研究可保留简短工作记录，无需专用格式。
- 收束时分别检查已有说法是否成立，以及是否漏掉足以改变整体判断的方向。单 Agent 同样执行；自查不冒充独立复核。

重要研究在宿主支持时并行分工，没有并行能力时沿同一方法分步推进。用户未限定资源时，不以固定搜索次数或轮数结束研究；简单问题直接完成。四份入口与方法文件净增加 568 个字符，协作文件由 1,029 减至 736 个字符；字符包含 Markdown，不能换算成 token 成本。

## 真实检索设计

执行前于 2026-09-10 11:06:26 UTC 冻结请求、两个版本及观察项，各版本 106 个文件。两名执行者从全新上下文分别读取指定版本，模型与思考设置继承同一父任务；未取得精确后端版本、token 或账单指标，不作估算。

两组用户请求相同：

> 请深入研究 Eaton（伊顿）未来两三年的投资前景，找出最值得关注的变化和机会，并给出有依据的判断；可以得出目前吸引力不足的结论。研究截止日期为2026年9月10日。

两组均只能独立执行公开搜索、网页读取及离线确定性计算，禁用 subagent 和工作流，不读取私有配置、Key、个人记录、父任务历史或其它版本。最终回答不超过 2,500 汉字，不设固定检索配额，也未提示应发现的项目、合作方或交易。执行者不读取 `expected_output`。

父任务同时检查公开原始来源，未向执行者提供这些发现。预先观察的是初始范围和收窄时机、新关系与判断的连接、失败来源处理、证据与反证、价格条件及实际资源使用；不是命中特定名字的计数。

本实验在一个宿主里禁用编排能力，检验单 Agent 是否能执行该方法。它没有在其它产品中运行；每组仅一次，实时搜索结果与资源消耗不固定，不能由结果推出跨模型、跨行业的稳定优势。

新版分派文本中的临时路径笔误已在同一条分派中明确纠正，实际读取记录指向正确快照；两个分派包装并非逐字相同。新版临近结束时收到一次仅询问进度的消息，没有新线索、期望答案或停止配额。版本在两组完成前未再修改。

## 独立匿名复核

两组完成后，将新版映射为 A、旧版为 B，移除版本标签和 skill 路径，向一个全新评审上下文提供原回答、检索参数与摘要、计算和来源记录。映射匿名但未随机化；评审没有读取 skill、父任务核对发现或预设赢家。它另外进行了 2 批、6 个打开条目的公开原文核查。

评审小幅偏好 B，即旧版，主要依据是更及时的架构路线，以及对另一地区固态变压器实际运行披露的吸收。它同时核实新版引用的 NUS 项目确实仍安排后续试验：两个来源描述不同项目，不能把新版的局部说法判为“伊顿完全没有运行产品”的错误。[伊顿亚洲披露](https://www.eaton.com/tw/zh-tw/company/news-insights/news-releases/2026/eaton-ai-high-density-power-semicon-taiwan-2026.html)、[NUS 原文](https://cde.nus.edu.sg/news/stdct-partners-eaton-to-validate-tropicalised-data-centre-power-architectures/)

评审肯定新版用施耐德实际交付作为竞争反证，并认为明确价格区间更便于比较。父任务保留一个限定：价格区间的算式正确不代表所选倍数已有足够根据，不能因此要求所有研究都给目标价。两组也都没有完成从产品份额、系统销售及扩产利润率到未来每股盈利的完整经营推演。这是本次输出的限度，不应通过补造参数满足形式。

评审全文和实际核查参数随 JSON 保存。单个评审、单个案例及不同资料取得路径，都不足以推出旧版或新版在一般任务中更好。
