# 盈利预测与价格入口：真实字段小样本审计

状态：小样本真实字段审计完成，未扩样本。范围冻结及执行日期：2026-09-22。取数时基线：`a5e176e`。

本审计验证现有公共接口能否为固定窗口的盈利预测变化计算提供可追溯输入，不验证投资收益或信号有效性。对应设计为 `handoff/quant-signal-design.md`。结果与紧凑原始字段保存在同名 JSON；不保存凭据。

## 预先冻结的范围

- 观察窗口：`T0=2026-06-22`、`T1=2026-09-18`；两日须由返回日线确认存在，不按公司寻找更有利端点。
- 目标预测财年：`F=2026`。端点预测最大年龄 180 个日历日；正 EPS 近零阈值为人民币 0.01 元/股。阈值仅为本次字段审计配置。
- 投资期限：本轮不设持有期、不计算后续收益。窗口只是材料比较范围。
- 获取研报自 `2025-12-24` 起，`max_pages=10`（最多返回 500 条，仅本地行上限）；日线 `frequency="D"`、`count=180`、`adjust="none"`。不因结果不理想调整窗口、换公司或扩样本。
- 证券：贵州茅台 `sh600519`（成熟大型公司，检验较多研报的可能性）、中芯国际 `sh688981`（半导体，检验机构差异及预测口径）、宁德时代 `sz300750`（检验跨市场上市/每股口径及公司行动证据）、宁波联合 `sh600051`（检验相对薄覆盖的可能性）。这些是选样理由，不预称实际存在上修、分歧、无覆盖或本窗口股本变化；以结果为准。
- 四家公司不是中证 500 的代表样本，也不因查询该指数而声称它们属于当前成分。另仅取一次 `index_constituents("000905", include_weights=False)`，检查实际行数、证券身份和来源日期。
- 每家公司各取一次研报、日线、近一年公告和分红送转记录，沿用既有默认来源、凭据配置、限流、超时与内部重试。`fetch_many(max_workers=3)` 仅组织这些显式调用。遇到上游失败记录原因，不无边界重复；不新增接口。
- 有材料时，每家公司最多抽查两份能覆盖窗口端点的研报原文；无匹配端点则抽查最新有效研报。另从公告标题中查找股本变化、增发配股、送转及分红线索；列表为空不等于确认无公司行动。

## 核验原则

分别记录证券身份、机构、预测财年、EPS 原值、列表展示日期、原文署名日期/时间、报告标识/原文位置、来源和抓取时间。首次可得时间及历史版本无法证明时保持未知；当前取回的历史材料不当作历史时点数据。

价格核对原价、币种、端点交易日和复权说明。每股口径及股本变化无法核实的公司不得自动视为可比较。本次 API 成功与原文核对成功分开计数。

## 执行结果

现有接口能取得大部分原始材料，但本轮没有任何公司完成全部机构、整个窗口的每股口径核验，不能把这些响应直接作为已合格的自动信号。真实材料确认了设计中的两个必要限制：**展示日期不等于原文日期，EPS 变化不一定是盈利预测变化。**

### 接入与验收结论

1. 列表日期、原文日期、抓取时间要分开保留；纯计算入口不得假装具备历史时点数据。供给端当前的三列预测年份与六份抽查原文匹配，不代表源会永久保留旧版本。
2. 每股基准未知或变化必须阻断自动命中。本轮三家有研报的公司都仍需补证；不能为了展示候选而将 `share_basis` 设为已核验。
3. 失败、成功空列表、过旧预测、新增机构和机构未更新分别表达。宁波研报 `provider_error`、中芯分红多源失败已原样记录，未进行无边界重试。
4. 取数时的日线信封/行没有 `symbol`、`code` 或显式价格币种；JSON 将请求身份单独保存，未伪装为源原生字段。后续实现若补请求身份，应说明来源；`amount_unit=CNY` 也不能冒充独立的价格币种字段。
5. 本轮仅通过了小样本输入可读性、选定原文的字段对应以及应阻断案例核验；**全部输入可自动比较、发现研究增量、收益预测能力都未通过验证。** 不扩大样本，不新增持久信号库，不把调用成功率写成投资有效性结论。
