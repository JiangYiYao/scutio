# 发现能力与预测变化入口：实施与验证

日期：2026-09-22。基线：`a5e176e`。开发诊断，不证明收益有效性。

## 实现

Scutio 增加独立的「发现」能力，仍为唯一 skill。入口按用户目标区分对象发现、产业前景、指定公司研究和已有判断复核；简单行情或表格筛选保持原有范围。候选选择、比较和覆盖归发现，经营机制与价格判断归研究，协作说明与估值方法各自单处维护。不新增固定角色、候选数、日常检索预算、自动记录或后台任务。

新增 `research.forecast_price_changes`，只接收已有研报、日线和显式窗口参数，不联网。它与相邻修订共用唯一 EPS 观测标准化，按同机构、同财年配对端点；严格区分未知口径、同日冲突、过旧、缺失、非正/近零盈利和可计算但不命中。日线信封补充已校验的请求身份及上市币种，明确其不是上游逐行身份的独立证明。筛选仍复用既有工具。

调用示例、字段与时间口径见 [toolkit](../../../skills/scutio/references/toolkit/04-research.md#固定窗口的预测与价格变化)。实现不提供股本自动换算、历史时点认证或收益回测。

## 代码与发布验证

- 全量离线回归：1244 通过、6 跳过、13 个 live 用例未纳入；耗时 33.90 秒。
- 新增预测与身份回归覆盖共享观测及固定窗口的数值、身份、日期、冲突、公司行动、缺失和展示限制；原有研究、行情与发布测试继续通过。
- Ruff 检查和格式检查通过；skill 校验通过。安装 ZIP 包含发现说明和计算入口，只有一个 `SKILL.md`，排除 `handoff/`、`evals/`。
- 验证命令和代码摘要见 [verification.json](verification.json)。静态检查不作为研究效果证据。

## 真实字段与计算回放

先冻结四家公司、2026-06-22 至 2026-09-18 窗口、FY2026、180 日陈旧度及 0.01 元近零阈值。17 次数据调用中 15 次成功，另抽查 6 份研报与 4 份公告。批次取数 10.804 秒，原文批次 6.908 秒；这不是端到端研究或冷缓存吞吐基准。

原文确认了有实质影响的风险：宁德时代同机构净利润预测未变，EPS 却因股本摊薄改变；茅台两份报告股本基准不同；中芯国际窗口内有实际增发。列表日期也不总等于原文署名日。宁波联合研报请求失败，不能视为无覆盖。

将同一批真实原值送入新入口，三家返回 `ok=True, partial=True, matched=None`，一家研报失败。所有公司均未获得完整可比证据，未自动命中；没有把未知字段补成相同口径。日线原始审计缺少身份字段，回放按保留的原请求上下文补充身份，并单列该来源性质。

详细原文、字段、错误、耗时及范围见 [真实审计](../2026-09-22-forecast-field-audit.md)、[输入](quant-inputs.json)、[计算输出](quant-results.json)。取得中证 500 最新 500 个唯一代码只验证名单入口；由于口径未通过，没有扩展全指数计算。当前成分和今天取回的历史报告不能用于声称不存在未来信息或幸存者偏差。

## 定向行为执行

实际运行十个冻结夹具，执行者未读预期答案；本次逐项符合预期。长期订单题确实读取三份材料，推进到 60 倍现有利润、约 42.9 倍条件性利润与资本开支/验收回款问题；没有停于名单。另覆盖稳定经营、薄关系排除、合作方价值归属、来源截断、量化命中边界、整家公司价值重点与三年期限。简单算术只答 20%，表格筛选只返回命中与缺失。

[完整答复与实际读取](behavior-run.json)、[实施者逐项检查](behavior-review.json)、[冻结题目及材料](behavior-manifest.json)分别保留。这是显式加载方法、同一上下文的批次诊断，不是独立重复、自动触发测试，也没有证明相对旧版改善；本轮未观察到指定公司研究被能力拆分削弱。

## 开放研究对照

在执行前冻结三个问题：无预设对象的 A 股机会、电网产业变化、非热门技术的包装行业。旧版 `a5e176e`、候选版和无 skill 各运行一次，共九次，均在新上下文执行。使用相同宿主工具及继承的模型设置，全部禁止内部子 agent；每次上限 36 个 web 条目、12 个 search 条目、8 批本地研究计算。该配额仅用于公平实验，不是日常 skill 的限制。

九次各用 36 个 web 条目；搜索 11–12 个，本地研究计算 1–2 批。全部问题以 2026-09-21 为截止日。各次来源、失败和完整回答见 [运行记录](run-summary.json) 及 `runs/r01.json` 至 `runs/r09.json`。两名评审只读匿名答案和去掉方法加载记录的研究轨迹，分别按 A→B→C 与 C→B→A 顺序评审，并独立抽查关键来源。

方法逐路径正文快照见 [methods.json](methods.json)；执行用的两个临时 Markdown 目录已在运行后删除，可按快照重新生成。预注册规则与版本摘要见 [manifest.json](manifest.json)。评审只承认双方一致指出、核实成立且没有重大事实或覆盖错误的实质增量；分歧不平均成胜出。执行者自记工具日志，不是独立网络抓包。旧版首个尝试误读合并方法快照，在检索前终止并换新上下文重跑，已记录排除。

初轮盲包在日志附注中残留了方法自述，评审发现后已排除该轮，清理元数据并用两个全新上下文重跑；原始研究答案未改。具体原因与旧盲包摘要见 [修正记录](blinding-correction.json)。

| 问题 | 新版与旧版 | 新版与无 skill | 本轮结论 |
|---|---|---|---|
| 无预设对象的 A 股机会 | 两位均判无明确优势 | 两位均判无明确优势 | 有不同且成立的经营发现，没有共同确认的净增益 |
| 电网产业机会 | 两位均判无明确优势 | 两位均判无明确优势 | 年度现金、订单结构与价格条件各有取舍 |
| 包装行业机会 | 两位均判无明确优势 | 一位判无明确优势，一位偏好无 skill | 保留分歧，不能判新版胜出 |

[评审一](judge-one.json)与[评审二](judge-two.json)各使用 12 个 web 条目独立核对来源。包装题无 skill 答案补查了共同候选的年度持续利润与资本开支后现金，两位均承认这是有价值的证据，但对是否足以压过新版的其他经营发现有分歧。电网题另发现旧版和无 skill 对会计估计影响的调查缺口；它没有被写成已证实的错误陈述，也没有用平均分抹掉。

**本轮未验证新版相对旧版或无 skill 有明确、可重复的发现增益。** 新版在市场题找到不同的恢复与分部利润解释，但不同名单和更多价格情景不等于更好的机会。保留能力拆分的组织收益，不将其宣传为已经增强选股能力；结论限于本轮问题与实验条件。

主对照排除了项目取数脚本与量化入口，只测试单 agent 的公开检索与方法使用，不衡量数据工具和并行协作的全部价值。未取得全部公司的准确截止日报价，有限独立核验也不是九份答案的全事实认证。模型精确后端与 token 用量不可得，实时检索有差异，且只有每题每条件一次执行；无 skill 运行仍可能看到已安装技能的名称元数据，但未加载正文。没有据此报告统计稳定性或全市场发现率。

## 遗漏抽查

在读取主流程答案前，另选美的集团、苏泊尔和五洲特纸，检查成熟大型业务、消费制造及较小包装上游的近期披露。美的的汇兑与套保损益分类、苏泊尔的现金转换、五洲特纸的盈利增长与现金差异，都提供可调查的问题，不能仅凭数值变化判断投资吸引力。[抽查材料与轨迹](omission-audit.json)保留来源、事实与推断。

主流程只有无 skill 市场答复提到美的，其余两家公司未进入九份答案；电网题不因此扣除不相关的行业覆盖。这不是已验证的遗漏机会集合：本轮没有补足三者的完整经营和目标日价格判断，也没有按新闻关注度量化分层。结果只能提醒有限检索会留下分支，不能估算全市场召回率或证明哪版漏掉了更多有吸引力的机会。

## 量化输入的研究回放

另用两个全新上下文，在相同发现方法、四家公司原始材料和原文核验摘录上比较「附加计算输出」与「没有计算输出」。本轮仅做冻结材料回放，禁止联网，并非设计中完整的开放发现增量实验；由于整个窗口的口径核验未通过，没有扩样本或宣称完成该后续验收。

[有入口答复](quant-with-run.json)与[无入口答复](quant-without-run.json)都正确拆出了宁德国信的股本影响、茅台的近似利润变化及中芯跨机构/增发问题，并区分宁波联合请求失败。两者也都做出了带口径限制的宁德估值容忍度演示，未将其包装成已确认投资机会。

独立评审先读取匿名 A/B 答案与相同冻结原始材料，再逐项复算，结论为**并列，没有核实的新经济解释或价格判断增益**。无入口答复的后续补证组织略具体，但不构成新增机会证据；两边读取/计算计数定义不同，不能声称节省了时间或成本。[评审及复算依据](quant-judge.json)与[映射](quant-blind-map.json)保留。

因此，本轮支持保留正确、可复用的计算工具，未验证它能提高发现效果。它继续是可选输入，不作为所有研究的门槛，不增加更多信号或全市场计算。历史收益验证仍缺历史成分、预测版本、首次可用时点与完整公司行动证据。


## 最终代码审查与修复

独立审查在既有测试之外复现了四项边界：[原审查记录](code-review.json)保留当时版本的复现与优先级。端点会受盘后同日冲突影响、未知口径时未更新计数漏报、供应商明示错票可在归一化中失去身份，以及两个极端有限值的中位数溢出，均纳入最后修复与回归。

修复后的相同真实输入回放单列在 [最终计算结果](quant-results-final.json)。三家仍为待补证，一家仍请求失败；未更新计数现分别为 5、1、4，包含已过期但确实沿用的记录，不能当作有效稳定预测。

`quant-results.json` 保留为两次研究答复实际看到的修复前输入，其摘要已记入量化实验清单。修复后仅重跑确定性计算与回归，没有重新生成两份研究答复；该次阴性研究对照是迭代中的诊断，不作为最终代码提升研究效果的证明。

四项原始复现均已消除，独立复核没有遗留的必须修复项。修复后相关测试 239 项通过，全量离线测试 1244 项通过；Ruff、skill 结构、文档链接、公开文件检查及发布包边界检查均通过。以上验收覆盖本轮实现与已列出的边界，不将研究效果或收益有效性视为已通过。
