# 发现

寻找并比较值得投资研究的对象，把重要线索推进为有依据的机会判断。可以从市场、产业变化或已有公司向外展开；用户无需先提供公司名单。指定对象的经营与价格分析使用 [研究](research.md)，检查原有选择使用 [复核](review.md)。

## 从开放问题开始

从上下文确定市场、投资期限、主题和现实约束。已有信息足以起步时，说明采用的范围并开始调查；只对会显著改变任务的歧义追问。投资期限、检索窗口、事件发生日和报告期分别处理：未来三年的机会，可能来自早年启动但尚未兑现的项目，不能只看近期新闻。

开始寻找候选前，用简短、用户能理解的话说明本轮选股策略：偏向什么机会、准备从哪些材料产生候选，以及怎样决定深入或排除。解释策略与用户期限和约束的关系；若从熟悉的大公司、特定行业或股息等指标起步，直接披露这个偏好。采用已有信息能支持的策略后继续调查，不增加例行确认步骤，也不把临时研究思路说成经过收益验证的投资策略。方向因新证据明显改变时，说明改变及原因。

只说“先筛选，再核对财报、估值和风险”仍是工作步骤；策略还应交代本轮更看重哪类回报来源、为什么，以及从何寻找这样的对象。可以先查看来源目录确定可查范围，但策略说明应早于定向检索或读取候选公司的材料。先前若只宣布使用 skill，应在深入候选前补上这层说明。

把宽泛方向转成可调查的变化与问题，按来源覆盖和新发现调整。例如：

| 入口 | 要解释的变化 |
|---|---|
| 资本配置 | 投资、收购、研发或人才转向哪里，相对原业务有多重要？ |
| 需求与供给 | 采购、交付、交期与产能退出是否改变短缺和议价权？ |
| 技术与经济性 | 成本下降或替代路线成熟后，谁开始采用，谁保留收益？ |
| 经营与竞争 | 盈利、现金流或份额变化来自持续改善、周期还是一次性因素？ |
| 特殊事项 | 分拆、重组和资产出售怎样改变股东权益、负债与回报路径？ |
| 经营与价格 | 稳定经营或持续兑现的公司，价格是否要求了过度悲观的结果？ |

这些是可选线索入口，不是固定的选股策略、必做清单或分工。开放寻找对象时，按策略选择能产生新候选的材料：盈利增长、估值等可比较条件使用下方市场筛选；订单、投产、重组等变化从跨公司披露索引、产业及关联方材料发现。二者可相互补充，不要求每次都执行两套流程。熟悉的公司可以作为初始线索，但定向搜索这些公司的优点不能代替开放发现。热门程度和冷门程度都不代表投资质量；同一事件的转载合并处理，保留原始披露和后续进展。

策略能由现有字段合理表达时，AI 主动选择范围、报告期和条件，说明这些是本轮初筛假设后执行，不等用户填写指标。阈值应对应研究目的、可比范围和口径；一次截面不能证明多年持续增长、现金回报或未来订单兑现。未盈利、重大转型等分支不沿用成熟公司的盈利和估值门槛，港美或目录外特征改用适用材料，不能用 A 股筛选代替跨市场覆盖。

## 选择并调查候选

一条线索要能说明发生了什么、为什么可能重要、影响哪些对象，以及查什么能区分不同解释。围绕潜在经济影响、证据状态、期限相关性和补证价值分配精力；不按统一财务阈值、新闻数量或资料丰富程度决定研究优先级。重大变化尚未进入利润、初始材料稀少时，先沿最有价值的缺口定向补证。

在当前任务中保留候选最初进入调查的依据，区分用户给定、已有知识提出、条件命中、跨公司材料发现和沿关系新增；补查后才取得的好消息不能倒写成初选理由。后续证据用于说明为什么保留、降级或排除。委派调查时一并传递本轮策略、已查范围和候选来源；仍需发现新对象的分支按变化或证据缺口分工，已知公司只作起点，避免所有分工都变成固定名单的验证。

核实客户、供应、股权和收入归属，把变化接到具体上市主体。沿关系主动调查，无需用户逐个授权候选；关系不实、经济影响微弱、优势易被抵消或不符范围时，说明原因并收束。新证据改变瓶颈或价值归属时，相应调整候选，不固守最早的名单。

重要候选按 [研究](research.md) 调查经营机制、时间路径和资金要求，并按 [经营前景与投资价值](research.md#经营前景与投资价值) 检验价格条件。传递已有材料、主张和缺口，避免重新抓取整套数据。比较谁可能保留更多经济价值、兑现条件怎样不同、价格要求是否合理；研究优先级与投资吸引力分别表达。

用户给定或 AI 从策略提出的条件均按 [程序筛选](../toolkit/screening.md) 执行：先查特征目录，再使用市场取数筛选；已有材料直接复用本地筛选。选择展示数量发生在筛选之后，不先挑熟悉公司再称市场筛选。目录外的经营特征从材料中提取和核实，不把主题词匹配替代经营判断。条件命中用于决定查什么，随后检查其经济原因、可持续性与价格要求；不能将命中当作机会已成立、市场尚未定价或未来超额收益。

## 如实说明覆盖

按 [数据索引](../toolkit/index.md) 选择跨对象入口，再用公司公告与原文核实关键线索。批量取数不自动建立全市场证券池，研报覆盖也不代表市场覆盖。复用接口的覆盖元数据，说明实际来源、查询窗口、取得与读取范围、涉及对象以及失败、缺失或截断；没有取得资料的对象不能算作未命中。证券数、公司数与文章数分别统计，同一公司的不同上市证券不直接算作不同机会。

宣称完整扫描前，须能核对所声明的证券范围与截止时点、资料类型和窗口、分页及截断、可比口径，以及实际扫描、失败和未取得的对象。遍历证券名单不等于发现了全部机会；抽样复查只能帮助发现遗漏。来源覆盖未知时保留未知，不用有限样本推断整个市场没有机会。

## 交付与收束

围绕最重要的机会判断和依据交付。简要说明实际策略和候选产生路径：程序筛选交代关键条件、范围和缺失；材料发现说明哪项变化带入对象；熟悉度起步如实说明。再解释重点候选怎样被保留或排除、变化怎样影响经营、价格要求什么，以及哪些事实会推翻判断，不等用户追问才交代来源，也不以“非全市场排名”替代。用户追问“为什么选这几家”时，先回答实际产生与取舍过程，不倒写初选依据。候选数量与篇幅随证据决定；吸引力不足可以明确排除，没有合适机会也可以如实作答，不为凑数量保留弱候选。

用户要求投资机会时，线索名单不构成完成。影响主要结论且仍能查明的经营与价格缺口在本轮继续推进；分支被排除、关键资料受阻或进一步取证不再改变判断时收束。确因资料受阻只能交付线索，明确机会判断尚未完成、证据支持到哪里及具体障碍。用户只要求线索时，交付深度相应缩小。

重要任务的分工、动态补证和汇合使用 [研究协作](../methods/pipeline.md)；机会判断同时交代重要候选的取舍与覆盖缺口。本轮材料按需复用，不新增自动研究档案、跨会话记忆或后台监控；用户要求保存研究时使用 [复盘](reflect.md)。
