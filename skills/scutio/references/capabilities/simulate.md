# 推演

回答“如果某个条件变化，会怎样”。可以独立执行，也可以嵌入研究或复核；不要求先完成整份公司报告。

## 基线、变量与边界

先明确要改变的变量、基线、时间范围，以及需要观察的结果。把已知数据、用户设定和 AI 引入的假设区分开。用户给出的假设可以直接用于条件计算，但不能因此写成已证实事实、公司指引或事件预测。

定性推演解释传导环节、抵消因素和适用边界。定量推演使用可检查的公式或脚本，注明输入单位、期间、币种和固定不变的项；有依赖关系的变量不能机械独立变动。只获取计算所需的数据。

例如用户给收入、成本和费用，并假设售价下降，可算在销量及成本不变时的利润变化；同时说明销量、产品结构和费用响应是未纳入的条件。没有可用参数时可以推导关系或求临界条件，不伪造基线。

## 收入与利润的条件计算

按业务机制选择需要计算的环节，不强行给所有行业套量×价：

```text
已知基线 + 明确假设
    → 分部或量价收入
    → 毛利及成本结构
    → 费用、税与其它影响
    → 对应口径的利润或现金流
```

收入到净利之间缺少费用、税或少数股东口径时，算到可支持的层级并披露缺项，不把毛利变化直接当作归母净利变化。计算前对齐报告期、累计/单季、归母/扣非/调整口径，无法对齐的部分不混算。

涉及营运资金、资本回报或估值现金流时，按 [财务与经营分析](../methods/financial-analysis.md) 核对科目重叠、经营与融资分类及行业适用性。已在利润或 CFO 中反映的投入不再次扣除，FCFF 与 FCFE 分别对应其资本提供者。

研究经营前景时，计算应接到关键机制：上线月份如何改变收入确认、投入是否随延期平移、老业务能否覆盖固定费用等。仅假设“利润达到某数，对应多少倍 PE”只说明估值敏感性，不能替代对怎样达到该利润的研究。用户只问估值算术时直接计算即可。

期末价值可以反映更远期的现金流；明确哪些价值来自期内经营、哪些依赖期后回报及剩余投入，不把验证节点或估值倍数上升直接当作必然收益。涉及股权结构变化时，把交易条件与稀释接到原股东的价值，合并规模本身不说明每股回报。

单期敏感性、盈亏平衡条件或多年情景按问题选择，不强制三情景、三年或价格目标。明确假设下的计算无需外部预测背书；将其解释为最可能结果或赋予概率则需要额外依据。

## 表达结果

先说明条件下的结果与最敏感变量，再给必要假设、计算关系和限制。重要结果可追到公式和输入，数值用脚本或确定性计算核对；没有参数就给符号关系、定性机制或具体缺口，不为填表补造精度。

计算正确与假设会发生是两件事。需要核实假设时转 [查证](verify.md)，检验原论点时转 [复核](review.md)。
