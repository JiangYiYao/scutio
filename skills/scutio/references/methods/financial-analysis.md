# 财务与经营分析

从业务机制选择证据，核对会计口径，解释变化来自哪里、是否需要持续投入，以及哪些判断仍取决于假设。以下方法按问题选用，不要求每次完成全套分析或估值。

## 业务驱动：先确定要解释什么

先明确盈利模式、主要分部和约束，再选择指标。例如收入变化可能来自销量、价格、产品结构、并购范围或汇率；平台成交额不等于收入，订单不等于交付，产能不等于销量。不同模式用能解释其变现的关系，不统一套量×价。

| 问题 | 优先核查 | 可以推进的判断 |
|---|---|---|
| 收入为何增长 | 分部量价、结构、订单转化、并表与汇率 | 哪部分来自可比业务增长，哪部分来自统计范围变化 |
| 利润为何改善 | 毛利、费用、投资收益、减值和税费 | 经营改善、会计估计与一次性因素各自的贡献 |
| 利润为何没变成现金 | 应收、存货、预收、应付及非现金项目 | 回款与支出时点、经营占用或确认口径的影响 |
| 增长需要多少投入 | 资本开支、经营营运资金、研发、人力及收购支出 | 增长的再投资需求、资金来源与回报约束 |

数字与解释相互核对：读表发现疑问，回到附注、经营披露或电话会，再检验解释是否与数字一致。卖方研报提供行业梳理与预测假设；评级和目标价不替代分析。已有材料足够时不重复取数，缺失项不按零处理。

## 会计口径：先判断能否直接比较

具体会计处理以相关公司适用准则及披露为准。

比较前对齐期间、币种、合并范围和指标定义。特别检查年度/季度/累计、归母/合并、报表/扣非/经调整、总额/净额确认及财年截止日。差异无法可靠调整时分别描述，说明哪些比较仍成立。

区分两种问题：报表是否忠实反映经营，以及经营结果是否持续、具有回报。一笔披露完整的一次性收益可以不持续，但不因此说明报表造假。管理层调整项保留从报表数到调整数的衔接；不能把每年反复出现的重组费或股权激励仅凭名称视为没有经济成本。

| 线索 | 核查材料与替代解释 |
|---|---|
| 收入与应收不同步 | 确认政策、账龄、合同、退货及后续回款；区分信用期、交付时点、增长和销售压力 |
| 库存或资本化支出增加 | 构成、项目进度、减值与费用政策；区分备货、业务结构、研发投入和费用递延 |
| 利润或毛利率突然上升 | 分部变化、并表、资产处置、补贴、减值转回和估计变更；不只归因于需求 |
| 现金与债务同时较高 | 受限资金、地域、可调拨性、期限及利息安排；账面现金不全等于可用现金 |
| 并购、商誉、关联交易或客户集中 | 收购贡献、整合、减值、交易条款及依赖变化；线索本身不是结论 |

只有附注或可核验事实支持时才进行分析调整，保留原数、调整原因和计算。审计意见、问询与管理层激励可帮助定位核查重点，不使用固定“红旗数量”评分。

## 变化归因：连接起点、贡献与终点

有可比数据时，从上期到本期拆出主要变化：收入中的量价/结构/并表/汇率，利润中的收入毛利/费用/非经营项/税费，现金中的经营结果/非现金项目/营运资金。分部与合并口径注意内部抵销，不能重复加总。

量价同时变化时存在交互项，说明拆分顺序或单列交互项；公司披露的有机增长口径优先核对，不自行假定排除了哪些因素。百分比与百分点、贡献额与贡献率分开，解释不了的余额标为未解释项，不按比例硬分摊。

例如：可比基期收入 100，本期 140，其中可比业务新增 15、收购新增 20、汇率新增 5。报表增长 40%，按该拆分口径可比业务增长 15%；不能把全部增长称为需求扩张，也不能由此证明可比增长会持续。

经营现金流增加还可能来自释放库存、收回应收或增加应付。先说明这些变化是否一次性、可持续或伴随经营代价；不能只因现金流改善就断言盈利质量提高，也不能只因现金流为负就判定经营恶化。

## 再投资、资本回报与现金

这一节默认用于一般非金融企业。先分清经营与融资、流量与存量，并保持分子分母覆盖的业务一致。

- **经营营运资金**：按披露定义选择应收、预付、存货、合同资产与应付、预收、合同负债等经营项。确认科目互不重叠，缺失项不补零。并购、汇率和重分类可能改变期末余额，余额差不自动等于现金流影响。CFO 已含相应营运资金变化时，不再次扣除。
- **再投资**：查看资本开支、营运资金及研发、人力、收购等投入，区分费用化和资本化。没有披露依据时不凭比例拆“维持性/增长性”开支；已经计入利润或现金流的投入不能再扣一次。
- **资本回报**：ROIC 使用同范围的税后经营利润与期间平均投入资本，列明现金、商誉、租赁等处理。ROE 上升应拆分盈利、周转及杠杆/权益变化；回购缩小权益也可能推高 ROE。历史平均回报不自动代表新增项目回报，投入资本很小或为负时不按比率排序。
- **增长与价值**：检验新增经营收益是否足以补偿新增资本及其风险。只有资本成本和回报口径有依据时才作定量比较；不为填表编造 WACC。增长快不自动等于创造更多价值。

`经营现金流−资本开支` 可作注明范围的现金余额简算，不能直接认定为 FCFF 或 FCFE。用于估值时，先确定面向全部资本还是普通股股东，再核对利息支付的现金流分类、税盾、净借款及其它资本提供者的归属，并与折现率对应。公司自定义 FCF 也应保留其调节表，不能只因同名就跨公司比较。

财务指标金额保留原始精度，展示单位服务问题，不将小额项目舍入为零。只有足够可比的序列才计算同比、CAGR、周转或回报；峰值、转型与一次性收益年份先解释代表性。

## 同行与行业边界

同行先比较业务、客户、资本强度、周期阶段及会计政策，再选择公司或分部层级。毛利率高可能来自业务组合或确认政策，PE 低也可能对应不同增长、风险和资本需求；差异需解释，不直接排名。

银行、保险等金融企业不套用上述一般企业的营运资金、净债务或 CFO−CAPEX 判断。银行按利差/费用收入、信用损失、资产质量与资本约束研究，保险按适用披露核对承保、投资与偿付能力；财务报表只是起点，需要相应监管和经营披露。数据缺失时停在能支持的判断层级。

周期企业需解释价格、产能利用率和资本投入所处阶段，不将景气峰值外推。研发或人力密集企业不能仅凭账面资产少认定无需再投资；进行研发资本化等分析调整时必须有可辩护的期限与摊销假设，并保留未调整结果。

港美证券用完整市场代码。分部、会计调整、指引和合同查公司 IR、港交所或 SEC 原文，区分 IFRS/GAAP 和管理层口径；A 股接口不适用不表示港美公司没有披露。

## 前瞻与表达

按“当前解释—支持证据—主要替代解释—剩余缺口”回答，简单问题不必成表。重要计算保留输入、公式、期间与调整项；来源及假设按 [证据与来源](evidence-and-sources.md) 处理。

需要前瞻时，把已核实机制与显式假设交给 [推演](../capabilities/simulate.md)。经营改善与股价方向分开；“超预期”需明确比较对象、预测年份、口径与信息时点。估值反推的隐含经营要求不是公司预测，也不直接证明市场参与者实际持有该预期。没有估值或预期数据仍可形成有依据的经营判断。
