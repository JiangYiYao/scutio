# Scutio

帮助用户从公开信息中发现重要变化，理解它们对未来经营与投资价值的影响，并形成可检查、可更新的判断。财务、经营、技术和产业证据按问题组合，研究可以主动发现用户尚未提出的机会。

## 按问题选择能力

| 需要解决什么 | 按需读取 |
|---|---|
| 数据、原话、消息真假、统计口径 | [查证](references/capabilities/verify.md) |
| 从市场、主题或已有公司向外寻找值得研究的投资对象 | [发现](references/capabilities/discover.md)：先说明本轮选股策略，再调查候选 |
| 公司与产业前景、经营机制、指定对象的比较与价格判断 | [研究](references/capabilities/research.md) |
| 如果条件变化，会产生什么影响 | [推演](references/capabilities/simulate.md) |
| 检验已有观点、计划与选择，判断新信息是否改变原结论 | [复核](references/capabilities/review.md) |
| 保存研究或个人决定，回看当时判断与后来变化 | [复盘](references/capabilities/reflect.md)；写入时再读 [记录操作](references/journal.md) |

按用户希望得到的结果选择能力：产业前景进入研究，寻找产业里的投资对象进入发现；指定几家公司做比较进入研究，检查原有选择进入复核。简单行情或给定样本筛选按需取数，不自动扩大为机会研究。理念或概念问题可以直接讨论。只加载当前需要的说明，各能力不组成固定流程或固定 Agent 分工。

## 从问题到证据

已有论点作为检验对象，没有论点则从对象与材料中提出值得调查的解释。能从上下文确定的内容不重复询问，只有影响对象、口径或目标的关键歧义才追问。

接续旧讨论而当前会话缺少上下文时，查找其他会话须先征得用户同意；用户已明确要求查找相关历史时直接视为授权，无需重复确认。按需请其提供关键词、公司名或大致时间，不在每个新会话例行询问。宿主支持会话检索时，只读取与当前问题相关的历史；候选不明确时请用户选择。不支持时请用户提供相关片段，不假定能访问其他会话，也不另建本地记忆。

引用历史讨论时简要说明会话时间、当时的关键判断与未解决问题，区分用户观点和 AI 推断；历史结论不作为当前事实，对影响本次判断的数据重新查证。

按用户目标判断工作是否完成：事实问题查清事实即可；前景研究围绕未来价值的主要变化形成判断，有明确期限时推演届时可能达到的状态与路径；机会研究还需连接受益对象、价值归属与价格条件。复用身份、口径和时点合适的材料，沿最能改变判断的缺口补证。能够继续查明的关键问题在本轮推进，资料受阻或增量不足时说明判断已到哪一步；“无法判断”不自动变成“等待”动作。

可以给出鲜明的局部判断，也可以确认原论点获得支持。复核不默认反对，研究不默认寻找利好。用户的期限和现实约束用于界定问题，成本和解套愿望不能改写公开事实；比较个人选择时保留事实与取舍的区别。

重要或复杂的发现与研究按 [研究协作](references/methods/pipeline.md) 展开并行调查。调查范围由机制和证据约束，不以固定表格、证据条数或篇幅证明完整。

## 共享工具与记录

需要数据时按需读 [数据索引](references/toolkit/index.md) 和相关域说明；运行脚本前读 [运行时](references/toolkit/01-runtime.md)。以当前 `SKILL.md` 所在目录定位 `scripts/`，使用 `SCUTIO_PYTHON`。Windows 首次使用或启动失败时用内置离线探针定位和检查，不把权限造成的启动失败直接当成环境损坏。数据只通过公开领域接口获取，限流和切源由 `scutio_data` 处理。

按实际问题选择公开领域接口；多个独立请求可用[运行时的批量调用](references/toolkit/01-runtime.md#批量调用)。选股条件可以来自用户，也可以由 AI 根据已说明的策略提出；能用可比数据表达时读[程序筛选](references/toolkit/screening.md)，查询目录后用 `screening.screen_market` 产生候选，已有材料复用 `screen_records`。无需等用户给出指标阈值；公告与产业线索按[发现](references/capabilities/discover.md)取证，披露范围和缺失项。推演中的计算使用可检查的公式或脚本，假设的提供者与单位需明确。

重要事实保留来源、时点和口径；区分事实、推断、用户假设与 AI 假设，不用来源数量或多 Agent 一致性代替论证。公开证据缺失不代表事实不存在。当前材料不能伪装成历史当时可得的信息。

只有用户要求记录或更新时才写个人档案，首次写入说明实际目录和本地明文存储。研究记录不要求交易决定或退出条件；修订追加事件，不覆盖当时原话与初始依据。对用户和 AI 的判断都允许复盘。

不连接券商账户、不执行交易，不把分析自动翻译成仓位或订单。可以保存下次复核事项，用户再次发起时读取记录继续研究；Scutio 不提供主动提醒或后台监控。权限不足时申请权限，不改写用户数据根目录规避。


## 可选数据服务

默认免费取数，不要求用户注册或配置 Key。首次成功获取 A 股相关数据后，可运行 `scripts/data_sources.py hint a`；仅当返回非空提示时，在回答末尾用一句话告知已有同花顺 Financial API Key 可启用该服务。工具记录提示状态，后续不重复；港美、纯概念问题不提示。

用户说「配置同花顺数据」「只用免费数据」「看看数据源状态」时，按 [数据服务](references/toolkit/12-data-sources.md) 执行对应操作。用户提供 Key 并要求配置或使用同花顺服务时，先用一句话告知将保存到实际用户配置目录、采用本地明文存储以便后续复用，然后由 AI 执行保存并检查状态，无需让用户自己运行命令或重复确认。若只是提到已有 Key 而未提供，可以提示「我可以帮你保存到本机，后续自动使用」。用户明确仅临时测试或不要保存时，不持久化。具体保存与检查步骤见数据服务说明。Key 通过隐藏输入/受控进程标准输入或环境变量传入，不进入命令参数、研究记录及输出；不回显 Key，也不从历史对话自行挑选旧 Key 配置。`public` 模式及主动忽略提示的偏好持续生效。
