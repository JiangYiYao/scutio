# 「发现」能力与量化线索入口

更新：2026-09-22。实施基线：`a5e176e`。原设计日期：2026-09-14。

## 已实现

- [发现能力设计](discovery-design.md)已落实为第六个能力，仍使用唯一的 `scutio` 入口。发现负责开放启动、候选选择、比较和覆盖；研究保留主动取证、经营机制、前景与价格判断。估值与协作方法各自单处维护。
- [量化线索设计](quant-signal-design.md)已落实为 `research.forecast_price_changes`：复用已取得的研报与未复权日线，比较同机构、同财年的固定窗口预测和参考 PE。它是无网络的纯计算，不新增策略、交易、后台监控或本地记忆。
- 预测标准化由 `research/consensus.py` 统一维护；同日冲突按整组处理，新旧入口共用身份、日期、财年与源字段校验。日线信封补充已验证的请求身份与上市币种，来源性质已写入说明。
- 路由、调用文档、行为用例和代码测试已同步。开发设计与实验仍留在 `handoff/`、`evals/`，不进入 skill 安装包。

使用方式见 [发现](../skills/scutio/references/capabilities/discover.md) 和 [预测与价格调用说明](../skills/scutio/references/toolkit/04-research.md#固定窗口的预测与价格变化)。

## 验证与边界

完整执行结果见 [实施与对照报告](../evals/reports/2026-09-22-discovery/report.md)，真实接口及原文核验见 [字段审计](../evals/reports/2026-09-22-forecast-field-audit.md)。报告分别说明代码正确性、研究行为、开放检索增量与收益证据，不能互相替代。

真实字段审计取得三家公司的研报及四家公司的端点日线，另有一家研报请求失败。原文确认 EPS 可能因股本基准变化而改变，也确认列表日期与报告署名日不同；三家均未完成整个窗口的全部口径核验，因此保留补证状态，没有包装成自动命中。

本轮没有扩大到中证 500 全量计算，没有新增全市场数据库或公共接口。取得最新成分不代表拥有历史证券池；有限样本也不能证明全市场没有机会。历史时点版本与公司行动不足，尚无收益回测或超额收益证据。
