# 「发现」能力交接

日期：2026-09-14。实现基线：`a92149b`。

## 当前状态

已形成并审阅 [发现能力设计](discovery-design.md)，尚未修改技能、数据接口或行为评测。此次提交只保存设计与交接材料。

目标是将「发现」独立为 Scutio 的第六个能力，支持用户没有预设公司时寻找投资机会。仍保留唯一的 `scutio` 技能入口。

## 已确定的方向

- 发现负责开放式启动、调查范围、候选选择与比较；研究负责经营机制、前景与价格判断；复核检验已有观点和选择。
- 按用户目标路由：「产业里有哪些机会」属于发现，「产业未来怎样发展」属于研究。指定公司研究仍可主动追踪新变化和关联方。
- 内容按职责迁移，估值与协作方法保持单处维护。能力可按需组合，不固定 Agent 角色、步骤、候选数量或日常研究预算。
- 用户要求投资机会时，应推进可查明的经营与价格问题；只取得线索时明确尚未完成的判断和障碍。现有数据不足以承诺全市场完整扫描。
